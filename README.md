# Portfolio

Personal software engineering portfolio for Osman Osmanaj.

## Open locally

Open `index.html` in a browser, use the VS Code Live Server extension, or run:

```bash
node preview.mjs
```

Then visit `http://127.0.0.1:4174`.

## Publish with GitHub Pages

After pushing this repository to GitHub, go to **Settings → Pages** and select **Deploy from a branch**, then choose `main` and `/ (root)`. GitHub will provide a `github.io` URL once deployment completes.

## Files

- `index.html`: page content and projects
- `styles.css`: visual design and responsive layout
- `script.js`: project slider, mobile menu, and email dialog
- `preview.mjs`: optional local preview server; GitHub Pages does not need it
